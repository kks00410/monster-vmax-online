# MONSTER VMAX ONLINE

네가 만든 9종의 몬스터 카드를 사용하는 실시간 1대1 온라인 카드 배틀 게임입니다.

## 포함된 기능

- 방 만들기 및 5자리 초대 코드 참가
- 플레이어별 시작 카드 5장, 시작 팀 1~3장 선택
- 실시간 양방향 게임 상태 동기화(Socket.IO)
- 배틀 몬 / 벤치 구성 및 자유 교체
- 턴마다 일반 에너지 1회 부착
- 손패 몬스터를 버리고 선택한 카드에 에너지 1개 부착
- 손패 카드를 벤치에 배치
- 카드 고유 기술, 특성, 회복, 보호막, 약화, 행동 불가, 벤치 피해
- 프라이즈 3장 선취 승리
- 접속이 끊겼을 때 브라우저의 재접속 정보로 방 복구
- 상대의 손패는 공개하지 않고, 서버에서 행동을 검증

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:10000`을 엽니다. 같은 컴퓨터에서 두 개의 브라우저 창을 열어 방 생성과 참가 흐름을 시험할 수 있습니다.

## 인터넷에 공개 배포하기

이 프로젝트는 브라우저 파일만 올리는 정적 사이트가 아니라, 실시간 대전을 처리하는 Node.js 서버가 필요합니다.

1. 이 폴더의 파일 전체를 Git 저장소에 올립니다. `public` 폴더와 `cards-data.json`도 반드시 포함해야 합니다.
2. Render에서 **New → Web Service**를 선택하고 해당 저장소를 연결합니다.
3. 다음 설정을 사용합니다.
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Health Check Path: `/health`
4. 배포가 끝나면 Render가 제공하는 HTTPS 주소를 친구에게 공유합니다.
5. 한 명은 **방 만들기**, 다른 한 명은 같은 사이트에서 **방 참가하기**를 누르고 5자리 코드를 입력합니다.

저장소에 포함된 `render.yaml`은 위 설정의 기본 예시입니다.

## 대전 데이터와 재접속

현재 방과 게임 상태는 서버 메모리에 저장됩니다. 서버가 재시작되거나 배포로 인스턴스가 교체되면 진행 중인 방이 초기화될 수 있습니다. 영구 보관이 필요한 계정·전적·랭킹 기능은 데이터베이스를 별도로 연결해야 합니다.

무료 호스팅은 일정 시간 사용하지 않으면 서버가 잠들 수 있어 첫 접속이나 재접속이 늦어질 수 있습니다. 실시간 대전 중 서버를 재배포하지 않는 것이 좋습니다.

## 파일 구조

```text
monster-vmax-online/
├─ public/
│  ├─ index.html      # 온라인 게임 화면 및 브라우저 로직
│  └─ cards.js        # 업로드한 9종 카드 이미지와 카드 데이터
├─ cards-data.json    # 서버에서 검증할 전투 능력치
├─ server.js          # 방 관리, 턴 진행, 전투 판정, Socket.IO
├─ package.json
├─ render.yaml
└─ README.md
```

## 참고

- 이 프로젝트는 1대1 친구 초대 대전용 첫 온라인 버전입니다.
- 로그인, 공개 매칭, 관전자, 채팅, 랭킹, 데이터베이스 저장은 아직 포함하지 않았습니다.
- 악의적인 요청을 막기 위해 방 코드 외에 별도의 플레이어 재접속 토큰을 사용합니다.
